Project Overview

I created an interactive, non-linear learning experience using Microsoft PowerPoint, designed with user control and accessibility in mind. Rather than a traditional slide presentation, this project functions as a self-guided learning tool where users choose what content to explore and in what order.

The design applies UX/UI principles such as clear navigation, intuitive interaction, visual hierarchy, and consistent layout. Advanced PowerPoint features—including action buttons, custom navigation, animations, and embedded media—were used intentionally to support usability and learning.

This project demonstrates my ability to design user-centered, interactive experiences and translate UX/UI thinking into instructional design.
