Build a Coloring Book

Project Overview

I designed a digital coloring book for JMU students with the goal of promoting mindfulness, stress reduction, and focus while introducing JMU-related topics. The project combines instructional design with user-centered visual design to create an engaging and calming experience for a college audience.

Using UX/UI principles, I focused on accessibility, clear layout, and intentional visual hierarchy. Each page was designed in Canva to practice manipulating design elements while maintaining a cohesive theme centered on campus life and student well-being. Captions and imagery were used to connect each illustration to a relevant JMU topic and guide user engagement.

This project demonstrates my ability to design purposeful, wellness-focused educational content and apply design tools strategically to support user experience and learning outcomes.
