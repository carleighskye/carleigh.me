NASA's Photo Gallery

Project Overview

Every day, NASA shares a new “Astronomy Picture of the Day” (APOD), featuring breathtaking images of galaxies, stars, planets, and beyond. My task for this project was to build a web app that connects to their public API and showcases these photos in a dynamic gallery. I added modal windows for each image generated, enlarging it and giving a description of what the user is seeing. I used HTML, CSS, and Javascript to put this together in Visual Studio Code. I wanted to keep NASA’s branding elements consistent within this site.
