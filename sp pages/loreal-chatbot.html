L'Oreal Chatbot

Project Overview

My task was to build a chatbot that helps users discover and understand L’Oréal’s extensive range of products—makeup, skincare, haircare, and fragrances—as well as provide personalized routines and recommendations. Users can browse real L’Oréal brand products, select the ones they want, and generate a personalized routine using AI. They can also ask follow-up questions about their routine, just like chatting with a real advisor. I used Cloudflare to secure my OpenAI API within this project. The OpenAI API used for this project was given to me by the Global Career Accelerator for the duration of the class, and is no longer active. The site is still functional, but is no longer able to return answers as the class has ended.
