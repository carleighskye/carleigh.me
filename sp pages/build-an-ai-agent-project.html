Build an AI Agent Project

Project Overview

I used Replit’s API agent and automation builder to create a time based automation agent to find me 10-15 entry level job listings relating to front end development, UI/UX design, and interactive design. I asked it to pull jobs from linkedin and indeed, and automatically filter jobs to show me ones that are in the NYC Metropolitan Area or remote. I also asked the agent to send me these jobs in an email, and give me specific details of each job, such as the title, company, location, a short description of the job, and information about the application. I asked Replit to send the information gathered from linkedin and indeed to GPT-5, and then used Resend’s API key to send the info from GPT-5 to my personal email in a clean, organized format. I set this email to be sent at 12pm daily.
